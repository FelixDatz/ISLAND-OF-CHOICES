# Fase 6.4 — Reactive Environment

Lingkungan bereaksi terhadap state permainan:
- Kotak perlengkapan berubah setelah dibuka.
- Pohon kelapa yang ditebang meninggalkan tunggul.
- Objek petunjuk berubah tampilan setelah diamati.
- Sungai menampilkan bentuk rakit, jembatan kayu, atau batu pijakan sesuai rute yang dipilih.
